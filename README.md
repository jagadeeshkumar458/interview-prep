# Interview Prep Desk

Interview questions organised by technology and concept, with answers, LinkedIn post summaries, a coding playground and mock interviews.

Open the site, then use it offline: after the first visit everything is cached. Install it from the browser menu ("Install app" / "Add to Home Screen").

Progress, notes and interview history are saved in your browser. Use **Backup** / **Restore** in the top bar to move them between devices.
